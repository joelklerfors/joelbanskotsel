# Joelbanskotsel

jag har tidigare jobbat på en golfbana som greenkeeper. Där skulle det behövas en sida för att logga vad man har gjort samt skulle behöva göras. hjälp mig att skapa en sådan som är användarvänlig och det blir extremt tydligt. jag vill kunna se när ett arbete gjordes senast och vilka som gjorde det. man skall kunna lägga in kommentarer med mera. golfbanan består av 18 hål, range, två stycken övningsgreener (humlegården och puttinggreen), övningsbunker och korthålsbana.
